Skill Training Completed

One home lab and fourteen sprints covering Windows Server, Azure, Linux, cloud and security. Each sprint ends with something you built and someone else can check. Certifications are optional gates along the way.

How it works

01

Skills first

You learn each skill once, and it counts toward every certification that tests it. That overlap saves time.

02

One lab

A VMware Workstation lab with two Windows domain controllers, a file server, a Linux router and two Linux servers. Build it in sprint S0 and keep it for every later sprint.

03

Prove it

Each sprint ends with a deliverable and a peer review. Book an exam once you meet the readiness gate.

Pick a track

All five tracks use the same sprints. Your pick sets which ones you do and whether you sit exams. Week counts assume about 8 hours a week.
