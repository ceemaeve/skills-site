Skill Training Completed

One home lab and 18 sprints, from IT basics through Windows Server, Azure, Linux, Cisco networking, cloud and security. Each sprint ends with something you built and someone else can check. Certifications are optional exams along the way.

How it works

01

Skills first

You learn each skill once, and it counts toward every certification that tests it. Learn DNS once, for example, and it counts toward Network+, AZ-802 and Linux+.

02

One lab

A VMware Workstation lab with two Windows domain controllers (the servers that handle sign-in), a file server, a Linux router and two Linux servers. You build it in S0 (2 weeks) and use it through S13.

03

Prove it

Each sprint ends with a deliverable that a study partner reviews. Book an exam once you meet the readiness checklist in the kit.

Pick a track

All 7 tracks use the same sprints. Your pick sets which ones you do and whether you sit exams. Week counts assume about 8 hours a week.

The 18 sprints

F1 to F3 are the Foundations sprints, for people new to IT. The core sprints, S0 to S13, start with Windows and Azure so the AZ-802 exam comes early, and each one adds a short Linux lab alongside the Windows work. N1 is the Cisco sprint for Track G.
