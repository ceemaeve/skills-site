How it works

01

Skills first

You learn each skill once, and it counts toward every certification that tests it. Learn DNS once, for example, and it counts toward Network+, AZ-802 and Linux+. See the skill map.

02

One lab

A VMware Workstation lab with two Windows domain controllers (the servers that handle sign-in), a file server, a Linux router and two Linux servers. You build it in S0 (2 weeks) and use it through S13.

03

Prove it

Each sprint ends with a deliverable that a study partner reviews. Find a study partner in the kit's Discussions, or run the self-check if you study alone. Book an exam once you meet the readiness checklist in the kit.

This site is a syllabus with labs. It has no lessons of its own: the teaching comes from Microsoft Learn, CompTIA, Cisco and the other official sources linked on the Resources page. Each sprint tells you what to build and how to prove it. Add Claude as a coach, as described under Take it with you, and the plan becomes guided study.

The kit is free and public on GitHub, so you can read, copy and correct any of it.

Pick a track

All 11 tracks use the same sprints. Your pick sets which ones you do and whether you sit exams. Week counts assume about 8 hours a week. Exam costs are US list prices for one attempt each; see Resources for each exam.

__TRACK_CARDS__

The 26 sprints

C1 starts every track: it teaches you to use Claude well for study and IT work, and C2 and C3 go further in Track I. P1 to P3 are the Copilot sprints: P1 is in Tracks A, B, D, E and J, P2 in Tracks B and J, and P3 in Track J. F1 to F3 are the Foundations sprints, for people new to IT. The core sprints, S0 to S13, start with Windows and Azure so the AZ-802 exam comes early, and each one adds a short Linux lab alongside the Windows work. N1 is the Cisco sprint for Track G, A1 the AWS sprint for Track H, and X1 the AI security sprint for Track K.
